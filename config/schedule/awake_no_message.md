# 主动唤醒

当前没有新的外部消息需要处理。

你现在拥有一个短暂的自主动作窗口。
这不是必须完成任务的提醒，也不是要求你证明自己“有事情可做”。

你可以静默，也可以利用这段时间探索、学习、构建、维护或继续未完成的事情。

## 从这里开始

工作区里有一份自主探索地图：

`/home/sandbox/memory/wiki/状态/探索方向清单.md`

它记录了当前可以进入的各条探索支线、已有线索、未闭环问题和可能的实验入口。

你不需要全部阅读，也不需要按顺序执行。
进入其中一个你认为此刻值得探索的方向即可。

你可以：

- 继续过去已经开始但尚未完成的工作；
- 调查一个自己仍不了解的问题；
- 改进或创建 Application / Skill；
- 验证一个尚未验证的猜想；
- 研究外部世界，并把有价值的信息带回来；
- 整理记忆、知识、代码或基础设施；
- 从最近发生的事情中发现新的问题；
- 创建一条新的探索支线。

## 做决定时

不要因为“主动唤醒”本身而强行制造工作。

优先考虑真正具有连续性、学习价值、实际价值或可能产生新能力的事情。
已经做过的事情不需要重复；没有足够理由时，静默是正常结果。

探索过程中可以自行扩大、修改或创建新的 Application、Skill、实验和探索支线。
工作区中的文件不是命令列表，而是你的探索地图。

如果决定行动，就直接行动；
