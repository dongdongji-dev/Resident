# 字体放置（可选）

表格渲染优先使用本目录下的两个字体文件：

- **拉丁**：Times New Roman（如 `Times New Roman.ttf`）
- **中文**：仿宋_GB2312（如 `仿宋_GB2312.ttf`）

识别规则：扫描本目录下的 `.ttf` / `.otf` / `.ttc`，文件名包含 `times`（拉丁）或
`仿宋`（中文）关键词即被采用。

> 字体文件因版权不随本仓库分发。**缺失时不会报错**：渲染会打一条 warning，并回退到
> 系统已安装的同语种字体（中文按 Noto / 思源 / 文泉驿等优先级挑选），出图不受影响；
> 想要规范版式就自行把字体文件放进本目录。
